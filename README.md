## Havan — Real-Time Chat App

Havan is a modern, responsive real-time chat application built with Next.js, React, TypeScript, MongoDB, and Ably.

**Features**
- User registration and authentication
- Real-time messaging
- Private conversations
- Message deletion and pinning
- Emoji picker
- Responsive, modern UI

**Live Demo:** https://havan-tau.vercel.app/

**Tech Stack:** Next.js · React · TypeScript · MongoDB · Mongoose · Ably · Vercel
